# Job Recommendation System using Machine Learning

## Project Description

This project recommends jobs to users based on their skills using TF-IDF and Cosine Similarity. It also predicts salary categories using Machine Learning.

## Features

- Data Preprocessing
- TF-IDF
- Cosine Similarity
- Random Forest Classification
- Job Recommendation
- Salary Category Prediction
- Confusion Matrix
- Feature Importance
- Model Comparison
- Accuracy Graph

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Joblib

## Dataset

Synthetic LinkedIn Dataset

- 10,000 Records
- Balanced Classes

## Model Performance

- Accuracy : 97.70%
- Precision : 92.09%
- Recall : 95.61%
- F1 Score : 93.74%
